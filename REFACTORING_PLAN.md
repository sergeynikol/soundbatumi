# План рефакторинга проекта Sound Batumi

## 📋 Обзор проекта

Проект представляет собой Django + Wagtail CMS приложение с интеграцией Telegram бота для управления заказами оборудования.

## 🎯 Цели рефакторинга

1. Удалить лишние файлы и код
2. Исправить проблемы безопасности
3. Улучшить читаемость и структуру кода
4. Добавить комментарии и документацию
5. Создать базовые тесты
6. Унифицировать стиль кода

---

## 📝 Детальный план действий

### Этап 1: Очистка проекта (Удаление лишних файлов)

#### 1.1 Удалить SQL дампы
- `sb.sql`
- `sb4.sql`
- **Причина:** Дампы БД не должны храниться в репозитории

#### 1.2 Удалить устаревшие файлы
- `get_group_id.py` (переместить функционал в management command, если нужен)
- **Причина:** Утилиты должны быть в management commands

#### 1.3 Удалить __pycache__ директории
- Все `__pycache__/` директории
- **Причина:** Генерируются автоматически, не должны быть в репозитории

#### 1.4 Объединить документацию

### Этап 3: Рефакторинг кода

#### 3.1 Исправить wagtail_views.py и urls.py
- **Проблема:** `wagtail_views.py` содержит устаревшие bulk actions views
- **Решение:** 
  - Удалить `wagtail_views.py` (bulk actions уже реализованы в `wagtail_admin.py`)
  - Удалить соответствующие URLs из `urls.py` (строки 33-43)

#### 3.2 Рефакторинг views.py
- **Проблемы:**
  - Очень длинный файл (900+ строк)
  - Дублирование логики логирования
  - Смешанные языки в комментариях
- **Решение:**
  - Разделить на модули:
    - `views/auth.py` - авторизация и регистрация
    - `views/orders.py` - создание заказов
    - `views/telegram.py` - Telegram callback
  - Добавить docstrings на русском языке
  - Унифицировать логирование

#### 3.3 Исправить модели (models.py)
- **Проблемы:**
  - Опечатка: `discription` → `description` (строки 51, 72, 92)
  - Отсутствие docstrings
  - Неправильные имена классов (например, `Footer_snipet_contact` → `FooterSnippetContact`)
- **Решение:**
  - Исправить опечатки
  - Добавить docstrings
  - Переименовать классы в соответствии с PEP 8
  - Создать миграцию для переименования полей

#### 3.4 Улучшить bot модуль
- **Файлы:**
  - `home/bot/bot.py`
  - `home/bot/handlers/common.py`
  - `home/bot/handlers/order_handlers.py`
  - `home/bot/keyboards/order_keyboards.py`
- **Действия:**
  - Добавить docstrings
  - Улучшить обработку ошибок
  - Унифицировать логирование

#### 3.5 Улучшить wagtail_admin.py
- Добавить docstrings
- Улучшить комментарии
- Оптимизировать запросы
