# Диагностика проблем с кнопкой "В обработку"

## Шаг 1: Проверьте webhook

Выполните команду для проверки текущего состояния webhook:

```bash
cd soundbatumi
source ../.venv/bin/activate
python manage.py check_webhook
```

Если webhook не настроен, установите его:

```bash
# Для продакшна (замените на ваш домен)
python manage.py check_webhook --set https://soundbatumi.com/api/telegram-callback/

# Для разработки (используйте ngrok)
python manage.py check_webhook --set https://your-ngrok-url.ngrok.io/api/telegram-callback/
```

## Шаг 2: Проверьте логи Django

Проверьте логи Django на наличие ошибок. При нажатии на кнопку "В обработку" должны появиться записи:

```bash
# В логах должно быть:
# - "Received raw webhook data: ..."
# - "Parsed webhook data: ..."
# - "Сообщение о заказе ... скопировано пользователю ..."
# - "Сообщение о заказе ... удалено из группы ..."
```

## Шаг 3: Проверьте права бота в группе

Бот должен иметь следующие права в группе:
- ✅ Право на отправку сообщений
- ✅ Право на удаление сообщений (или быть администратором)
- ✅ Право на чтение сообщений

Проверьте настройки группы:
1. Откройте группу в Telegram
2. Перейдите в "Настройки группы" → "Администраторы"
3. Найдите вашего бота
4. Убедитесь, что у бота есть права на удаление сообщений

## Шаг 4: Проверьте, что пользователь начал диалог с ботом

Для отправки сообщений в личный чат пользователя, пользователь должен:
1. Найти бота в Telegram
2. Нажать "Start" или отправить команду `/start`

Без этого бот не сможет отправлять сообщения в личный чат.

## Шаг 5: Проверьте настройки в .env

Убедитесь, что в `.env` файле правильно настроены:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_GROUP_ID=-1001234567890
```

## Шаг 6: Тестовая отправка сообщения

Попробуйте отправить тестовое сообщение боту в группе:

```bash
python manage.py test_telegram_notification --order-number LAST
```

Это должно отправить сообщение с кнопкой в группу. Затем попробуйте нажать на кнопку.

## Шаг 7: Проверьте формат callback_data

В логах должно быть видно:
- `callback_data: process_order_123` (где 123 - это ID заказа)
- `chat_id: -1001234567890` (ID группы)
- `message_id: 123` (ID сообщения)
- `user_id: 123456789` (ID пользователя, который нажал кнопку)

## Частые проблемы:

### Проблема 1: Webhook не настроен
**Симптомы:** Кнопка не реагирует на нажатие
**Решение:** Установите webhook командой `python manage.py check_webhook --set URL`

### Проблема 2: Бот не может удалить сообщение
**Симптомы:** В логах ошибка "not enough rights" или "message can't be deleted"
**Решение:** Дайте боту права администратора или права на удаление сообщений в группе

### Проблема 3: Бот не может отправить сообщение пользователю
**Симптомы:** В логах ошибка "bot was blocked" или "chat not found"
**Решение:** Пользователь должен начать диалог с ботом (отправить `/start`)

### Проблема 4: Webhook получает данные, но ничего не происходит
**Симптомы:** В логах есть "Received raw webhook data", но нет дальнейших действий
**Решение:** Проверьте логи на наличие ошибок. Убедитесь, что `callback_data` начинается с `process_order_`

## Отладка через логи

Включите подробное логирование в Django settings:

```python
LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
        },
    },
    'loggers': {
        'home.views': {
            'handlers': ['console'],
            'level': 'DEBUG',
        },
    },
}
```

Затем при нажатии на кнопку проверьте вывод в консоли или логах.
