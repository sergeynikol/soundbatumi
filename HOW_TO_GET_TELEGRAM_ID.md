# Как узнать свой Telegram ID (TELEGRAM_ADMIN_IDS)

## Способ 1: Через бота @userinfobot (самый простой) ⭐

1. Откройте Telegram (на телефоне или компьютере)
2. Найдите бота: `@userinfobot` (или перейдите по ссылке: https://t.me/userinfobot)
3. Нажмите кнопку **START** или отправьте любое сообщение
4. Бот сразу покажет ваш **ID** - это число, например: `123456789`

## Способ 2: Через бота @getidsbot

1. Откройте Telegram
2. Найдите бота: `@getidsbot` (https://t.me/getidsbot)
3. Отправьте команду `/start`
4. Бот покажет ваш ID

## Способ 3: Через бота @RawDataBot

1. Откройте Telegram
2. Найдите бота: `@RawDataBot` (https://t.me/RawDataBot)
3. Отправьте `/start`
4. В ответе найдите строку `"id": 123456789` - это ваш ID

## Как настроить TELEGRAM_ADMIN_IDS

После того как вы узнали свой ID (или ID всех администраторов):

### Если один администратор:
```bash
TELEGRAM_ADMIN_IDS=123456789
```

### Если несколько администраторов (через запятую):
```bash
TELEGRAM_ADMIN_IDS=123456789,987654321,111222333
```

### Где добавить:

1. **В файл `.env`** (рекомендуется):
   - Откройте файл `.env` в папке `soundbatumi/`
   - Добавьте строку:
     ```
     TELEGRAM_ADMIN_IDS=ваш_id_здесь
     ```
   - Или если несколько администраторов:
     ```
     TELEGRAM_ADMIN_IDS=123456789,987654321
     ```

2. **В переменные окружения системы** (для продакшена)

## Пример полного `.env` файла:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_ADMIN_IDS=123456789
SECRET_KEY=your_secret_key_here
```

## Как проверить, что всё работает:

1. Убедитесь, что `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_IDS` установлены в `.env`
2. Создайте тестовый заказ на сайте
3. Проверьте, что уведомление пришло в Telegram
4. Если не пришло, проверьте логи Django на наличие ошибок

## Важные замечания:

- ✅ ID - это **число**, не username (не `@username`)
- ✅ ID у каждого пользователя уникальный
- ✅ ID не меняется (в отличие от username)
- ✅ Если несколько администраторов, указывайте ID через запятую **без пробелов**
- ⚠️ Убедитесь, что бот может отправлять сообщения администраторам (они должны начать диалог с ботом первыми или бот должен быть в группе)
