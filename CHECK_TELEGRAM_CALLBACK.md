# Инструкция по проверке работы кнопки "В обработку"

## Способ 1: Проверка логов Django в реальном времени

1. Откройте терминал, где запущен Django сервер
2. При нажатии кнопки "В обработку" в Telegram вы увидите подробные логи:
   - `Попытка скопировать сообщение: chat_id=...`
   - `✅ Сообщение о заказе ... скопировано пользователю ...`
   - `Попытка удалить сообщение: chat_id=..., message_id=...`
   - `✅ Сообщение о заказе ... удалено из группы ...`
   - Или ошибки с описанием проблемы

## Способ 2: Использование команды для тестирования

Если у вас есть данные о сообщении в группе, можете протестировать callback:

```bash
python manage.py test_callback \
  --order-id 1 \
  --chat-id -1001234567890 \
  --message-id 123 \
  --user-id 123456789
```

Где:
- `--order-id` - ID заказа из базы данных
- `--chat-id` - ID группы (отрицательное число, например -1001234567890)
- `--message-id` - ID сообщения в группе
- `--user-id` - ID пользователя, который нажимает кнопку

## Способ 3: Проверка через логи файла (если настроено логирование в файл)

Если логирование настроено в файл, проверьте файл логов:
```bash
tail -f /path/to/logfile.log | grep -i "telegram\|callback\|заказ"
```

## Что проверить при проблемах:

### 1. Webhook настроен?
```bash
python manage.py check_webhook
```

### 2. Бот имеет права администратора в группе?
- Откройте настройки группы в Telegram
- Перейдите в "Администраторы"
- Убедитесь, что бот добавлен как администратор
- Убедитесь, что у бота есть права на удаление сообщений

### 3. Пользователь начал диалог с ботом?
- Пользователь должен написать боту `/start` или любое сообщение
- Бот должен иметь возможность отправлять сообщения пользователю

### 4. Проверьте ошибки в логах:
- `❌` - критические ошибки
- `⚠️` - предупреждения
- `✅` - успешные операции

## Типичные ошибки:

1. **"not enough rights"** - бот не имеет прав на удаление сообщений
   - Решение: дайте боту права администратора

2. **"bot was blocked"** или **"chat not found"** - пользователь не начал диалог с ботом
   - Решение: пользователь должен написать боту `/start`

3. **"message to delete not found"** - сообщение уже удалено
   - Это нормально, сообщение уже было удалено ранее

4. **Webhook не отвечает** - проверьте, что сервер доступен и webhook настроен
   - Решение: `python manage.py check_webhook --set https://yourdomain.com/api/telegram-callback/`
