# Исправление ошибки "Bot domain invalid" для Telegram Login Widget

## Проблема
Ошибка "Bot domain invalid" возникает, когда домен вашего сайта не добавлен в настройки Telegram бота в BotFather.

## Решение

### Шаг 1: Откройте BotFather в Telegram
1. Откройте Telegram
2. Найдите бота [@BotFather](https://t.me/BotFather)
3. Нажмите START

### Шаг 2: Выберите вашего бота
Отправьте команду:
```
/mybots
```
Выберите вашего бота (`SoundBatumi_bot`)

### Шаг 3: Настройте домен
1. В меню бота выберите **"Bot Settings"** (Настройки бота)
2. Выберите **"Domain"** (Домен)
3. Отправьте домен вашего сайта, например:
   - Для локальной разработки: `127.0.0.1` или `localhost`
   - Для продакшена: `soundbatumi.com` или `www.soundbatumi.com`

### Шаг 4: Подтверждение
BotFather подтвердит, что домен добавлен:
```
Success! The domain example.com is now set for your bot.
```

## Важно!

### Для локальной разработки:
- Используйте домен `127.0.0.1` или `localhost`
- Telegram виджет будет работать только при открытии сайта через `http://127.0.0.1:8000/` или `http://localhost:8000/`

### Для продакшена:
- Добавьте реальный домен (например: `soundbatumi.com`)
- Убедитесь, что сайт работает по HTTPS
- Telegram Login Widget **требует HTTPS** для работы в продакшене

## Проверка домена

После добавления домена:
1. Перезагрузите страницу сайта
2. Откройте модальное окно авторизации
3. Кнопка Telegram должна появиться и работать

## Если проблема сохраняется:

1. **Проверьте домен в BotFather:**
   - Откройте `/mybots` → выберите бота → "Bot Settings" → "Domain"
   - Убедитесь, что домен точно совпадает с доменом, на котором открыт сайт

2. **Для локальной разработки:**
   - Используйте `127.0.0.1` вместо `localhost` (или наоборот)
   - Попробуйте добавить оба варианта

3. **Проверьте консоль браузера:**
   - Откройте Developer Tools (F12)
   - Перейдите на вкладку Console
   - Проверьте, нет ли других ошибок

## Текущие настройки проекта:

Согласно настройкам в `settings/base.py`:
- `WAGTAILADMIN_BASE_URL = "http://example.com"` (требует изменения на реальный домен)
- `ALLOWED_HOSTS` настроен в `settings/dev.py` или `settings/production.py`
