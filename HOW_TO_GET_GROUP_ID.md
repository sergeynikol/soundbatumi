# Как получить ID группы Telegram

Для работы бота в группе необходимо настроить `TELEGRAM_GROUP_ID` в файле `.env`.

## Способ 1: Использование бота @userinfobot

1. Добавьте бота `@userinfobot` в вашу группу
2. Отправьте любое сообщение в группу
3. Бот ответит с информацией о группе, включая ID
4. ID группы будет отрицательным числом (например: `-1001234567890`)

## Способ 2: Использование бота @RawDataBot

1. Добавьте бота `@RawDataBot` в вашу группу
2. Отправьте команду `/start` в группе
3. Бот отправит JSON с информацией о группе
4. Найдите поле `"id"` в объекте `"chat"` - это ID группы

## Способ 3: Использование username группы

Если у группы есть публичный username (например, `@mygroup`), вы можете использовать его:

```
TELEGRAM_GROUP_ID=@mygroup
```

## Настройка в .env

Добавьте в файл `.env`:

```bash
# ID группы (отрицательное число) или username группы (с @)
TELEGRAM_GROUP_ID=-1001234567890

# Или используйте username:
# TELEGRAM_GROUP_ID=@mygroup
```

## Важно

- **Бот должен быть добавлен в группу** и иметь права на отправку сообщений
- **Для супергрупп** ID будет отрицательным числом, начинающимся с `-100`
- **Для обычных групп** ID будет отрицательным числом
- Если используется **username**, группа должна быть публичной

## Проверка работы

После настройки создайте тестовый заказ и проверьте, что сообщение приходит в группу.
